# kartomed_packages

Данные для приложения Kartomed, которые обновляются без выпуска новой версии приложения.
Сейчас это справочники: диагнозы, лекарства, симптомы, специализации врачей, прививки, аллергены.

Раз в месяц GitHub сам собирает справочники из официальных источников, проверяет их и, если
что-то изменилось, выкладывает. Приложение раз в 30 дней (и по кнопке в «Справочнике») скачивает
только изменившиеся справочники.

## Где лежат опубликованные файлы

| Адрес | Что это |
|---|---|
| `https://kartomed.foleks.com/dictionaries/manifest.json` | Основной адрес: хранилище Cloudflare R2 `kartomed` |
| `https://alxpanther.github.io/kartomed_packages/dictionaries/manifest.json` | Запасная копия: GitHub Pages этого репозитория |
| `public/` в этом репозитории | Те же файлы; из них же выпуск приложения берёт встроенную копию |

В корне обоих адресов — страница `index.html` со списком справочников и источников: её адрес
назван в описании Google Play, и проверяющие Google его открывают.

## Состав публикации (`public/dictionaries/`)

- `<имя>.json.gz` — записи справочника, `<имя>.groups.json` — дерево каталога;
- `dosage.json` — формы выпуска и единицы, `vaccine_diseases.json` — болезни, от которых защищают прививки;
- `manifest.json`:
  - `format` — устройство файлов (сейчас `1`). Если устройство меняется — новое число; старые
    версии приложения такие файлы не берут. **Менять устройство — только вместе с приложением.**
  - `built` — дата сборки. Приложение берёт ту копию (встроенную или скачанную), у которой дата новее.
  - `dictionaries` — для каждого справочника: тип, версия (отпечаток содержимого), число записей.
  - `files` — для каждого файла: размер и SHA-256. Приложение принимает файл только при совпадении обоих.

## Как устроена сборка

```
dictionaries/
  build_diagnoses.dart   диагнозы: украинское, российское и американское издания + свои синонимы
  build_drugs.dart       лекарства: государственный реестр Украины (data.gov.ua)
  build_own_lists.dart   свои списки: симптомы, специализации, прививки, аллергены
  publish.dart           проверка и публикация в public/
  src/                   общие части: запись файлов, транслитерация, исправление смешанных азбук,
                         проверки публикации (publication.dart), страница (page.dart)
  data/                  свои данные: синонимы, списки, формы выпуска, единицы, группы лекарств
  sources/               файлы источников, которые кладёт владелец (российское издание)
test/                    тесты скриптов
build_dictionaries.sh    вся сборка целиком
.github/workflows/kartomed-dictionaries.yml   ежемесячный запуск
```

Справочник **не публикуется** (остаются прежние файлы, запуск завершается ошибкой, приходит
сообщение в Telegram), если: источник недоступен, файл в другом формате, справочник не собрался,
число записей упало больше чем на 10 % или число названий на каком-то языке упало больше чем на
10 %, в словах смешаны похожие буквы кириллицы и латиницы. Публикация — всё или ничего: если
отказ по одному справочнику, не выкладывается ни один.

Если ничего не изменилось — ничего не коммитится и не выкладывается.

## Российское издание диагнозов

Портал Минздрава России (`nsi.rosminzdrav.ru`) не отвечает из-за границы, в том числе серверам
GitHub. Поэтому:

1. Пока в репозитории нет своего файла, берётся неизменённая выгрузка версии 2.27 из открытого
   зеркала на GitHub (получена зеркалом 24.11.2025).
2. Чтобы обновить: скачать с портала свежую выгрузку справочника OID 1.2.643.5.1.13.13.11.1005 в
   формате CSV, положить как `dictionaries/sources/diagnoses_ru.csv` и закоммитить.
3. Если выгрузке больше года (по дате коммита файла, а для зеркала — по 24.11.2025), сборка
   присылает предупреждение в Telegram, но справочники всё равно публикуются.

## Запуск

Вручную на компьютере (нужны Dart, `pdftotext` из `poppler-utils`, `unzip`, `git`):

```bash
dart pub get
./build_dictionaries.sh
```

На GitHub: вкладка **Actions → Kartomed dictionaries → Run workflow**. Сам запускается 5-го числа
каждого месяца в 06:00 по UTC. Если вручную поправить файлы в `public/` и отправить в `main`, они
выкладываются без сборки.

## Что нужно один раз настроить

Секреты репозитория (**Settings → Secrets and variables → Actions**):

| Секрет | Зачем |
|---|---|
| `CLOUDFLARE_API_TOKEN` | Запись в хранилище R2 `kartomed` |
| `CLOUDFLARE_ACCOUNT_ID` | Номер учётной записи Cloudflare |
| `TELEGRAM_BOT_TOKEN` | Сообщения об ошибках и предупреждениях |
| `TELEGRAM_CHAT_ID` | Куда их присылать |

GitHub Pages: **Settings → Pages → Source: GitHub Actions** (уже включено).

Cloudflare: хранилище само не открывает страницу по адресу без имени файла. Чтобы
`https://kartomed.foleks.com/` показывал `index.html`, нужно правило замены адреса
(**Rules → Transform Rules → URL Rewrite**: если путь равен `/`, переписать на `/index.html`) —
так же, как сделано для `tarrifs.foleks.com`.

## Связь с приложением

- Адреса зашиты в приложение: `AppLinks.dictionaryPublications` (`lib/core/app_links.dart`).
- Перед выпуском приложения `_build_dictionaries.sh` в проекте kartomed забирает опубликованные
  файлы во встроенную копию (`tool/dictionaries/sync_from_site.dart`) и проверяет их тестами
  приложения. Свои данные справочников правятся **только здесь**.
- Источники справочников перечислены в приложении («О приложении → Правовая информация»), в
  описании Google Play и на странице `index.html` — при новом источнике поправить все три.
